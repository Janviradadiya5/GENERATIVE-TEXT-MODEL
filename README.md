# GENERATIVE-TEXT-MODEL


This project is a **Generative Text Model** that uses the powerful GPT-2 model from HuggingFace's Transformers library to generate coherent and creative text based on user input prompts — no TensorFlow required.

---

## 🚀 Features

- 🤖 AI-powered text generation using GPT-2
- ⌨️ Accepts dynamic user input (prompt-based)
- 📜 Generates meaningful paragraphs from short prompts
- 🧪 Works in Python console or Jupyter Notebook

---
